# VEDANT.EXE

> Building across software, systems, and the physical world.

VEDANT.EXE is a cinematic, Minecraft-inspired 3D developer portfolio designed to present my projects, technical experience, and skills through an interactive voxel environment.

Instead of a conventional portfolio layout, the experience is built around a connected 3D world, guided camera movements, and minimal web-based interfaces.

## Vision

The portfolio is envisioned as a journey through a Minecraft-inspired world:

- **Home:** A cinematic introduction and central hub.
- **Workshop:** A showcase of selected development projects.
- **Research Wing:** Technical skills, education, experience, and achievements.
- **Return Path:** A final journey back to the central hub.

The experience will combine voxel-inspired environments with modern web technologies.

## Planned Features

- Minecraft-inspired 3D environment.
- Cinematic loading and world-generation sequence.

- Skills and experience section.
- Responsive HTML-based information overlays.
- Optimized GLB assets.

## Featured Projects

The planned project showcase currently includes:

- **GeoFence** — A pet tracking and virtual fencing system.
- **EviLog** — A low-cost, hardware-assisted evidence tracking system that digitally records evidence movement and maintains its chain of custody.
- **SafePath** — An offline emergency assistant application.

Project details and demonstrations will be added as the portfolio develops.

## Getting Started

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Navigate into the project:

```bash
cd Vedant-Portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
